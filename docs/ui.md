# Muse 前端 UI 改造需求文档 —— 对标 Google AI Studio

## 一、总体设计理念

将现有的**多页面路由切换架构**改造为**单页面三栏布局**的沉浸式对话体验，对标 Google AI Studio 的 UI 设计。核心原则：**主屏只展示对话，所有配置/管理功能收纳到侧边栏或面板中。**

---

## 二、整体布局结构

### 2.1 布局架构（从左到右）

```
┌──────────────┬─────────────────────────────────┬──────────────────────┐
│              │                                 │                      │
│  左侧边栏     │        主对话区域                 │   右侧面板            │
│  (Left       │      (Main Chat Area)           │  (Right Panel)       │
│   Sidebar)   │                                 │                      │
│              │                                 │                      │
│  宽度:260px   │       自适应填充                  │   宽度:360px          │
│  可折叠       │                                 │   可折叠/可切换        │
│              │                                 │                      │
└──────────────┴─────────────────────────────────┴──────────────────────┘
```

### 2.2 响应式策略

| 屏幕宽度 | 左侧边栏 | 主对话区 | 右侧面板 |
|---------|---------|---------|---------|
| ≥1200px | 常驻显示 | 自适应 | 常驻显示 |
| 768~1199px | 可收起图标栏（72px） | 自适应 | 点击按钮弹出抽屉 |
| <768px | 汉堡菜单抽屉 | 全屏 | 底部抽屉或全屏弹出 |

## 三、左侧边栏（Left Sidebar）

### 3.1 顶部区域

- **Logo + 应用名称**：保留现有 "Muse" Logo，折叠时只显示图标 "M"
- **新建对话按钮**：参考 AI Studio 的 `+ Create new chat` 按钮
    - 样式：圆角矩形按钮，左侧有 "+" 图标
    - 位置：Logo 下方，固定不滚动
    - 点击行为：创建新会话，自动进入对话状态

### 3.2 对话历史列表（核心区域）

替换现有的多页面导航菜单，改为**对话会话列表**：

- 每个会话项显示：
    - 角色头像（圆形，36px）
    - 会话名称 / 角色名称
    - 最后一条消息的时间/预览（截断显示）
    - hover 时显示操作按钮（删除、重命名）
- 列表支持滚动，使用虚拟滚动优化（如果会话量大）
- **当前激活的会话高亮显示**（参考 AI Studio 的蓝色背景高亮）
- 按照更新时间倒序排列

### 3.3 底部快捷入口区域

将原有的页面导航收纳为底部的**图标按钮组**：

```
┌─────────────────────────┐
│  [角色] [世界书] [预设]    │
│  [正则] [设置]            │
│                         │
│  v1.0.0                 │
└─────────────────────────┘
```

- 每个按钮为**图标 + Tooltip文字**
- 点击这些按钮后，对应的管理界面在**右侧面板**中打开（而非路由跳转）
- 折叠状态下只显示图标列
- 分隔线将对话列表和快捷入口分开

### 3.4 折叠行为

- 折叠按钮位于底部区域
- 折叠后宽度收缩到 72px
- 对话列表只显示头像
- 快捷入口只显示图标
- hover 某项时显示 Tooltip

## 四、主对话区域（Main Chat Area）

### 4.1 顶部工具栏

参考 AI Studio 的顶部栏，包含以下元素：

```
┌──────────────────────────────────────────────────────────────────┐
│  [≡] 角色名称 ▾    |  模型: GPT-4o ▾  |  温度: 0.9  |  [⚙] [☀]  │
└──────────────────────────────────────────────────────────────────┘
```

- **左侧**：
    - 移动端汉堡菜单按钮
    - 当前对话的角色名称 + 头像
    - 点击角色名可弹出角色快捷切换下拉菜单
- **中间**（参考 AI Studio 的模型选择器）：
    - 当前使用的模型名称（下拉选择器，可快速切换 API 配置/模型）
    - 温度参数显示（可点击快速调整）
- **右侧**：
    - 右侧面板展开/收起按钮
    - 主题切换按钮（日/夜模式）
    - 用户菜单（头像下拉菜单）

### 4.2 对话消息区域

保留现有的消息展示逻辑，但调整样式：

- **参考 AI Studio 的消息气泡风格**：
    - 用户消息：右对齐，带主题色背景的气泡
    - AI回复：左对齐，带角色头像，浅色/透明背景
    - 消息之间有适当间距（16~20px）
- **空状态**（无消息时）：
    - 参考 AI Studio 的欢迎界面
    - 显示 Muse Logo + 欢迎文案
    - 可选择角色开始对话的快捷入口（卡片式角色选择器）
    - 例如："选择一个角色开始对话" + 最近使用的角色卡片网格
- 消息操作按钮（编辑、复制、删除、重新生成）hover 时显示

### 4.3 输入区域

参考 AI Studio 的底部输入区域：

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  [📎]  在这里输入消息...                [Token计数] [发送▶] │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- **输入框**：
    - 多行自适应高度的 textarea
    - 最大高度 200px，超出后内部滚动
    - placeholder: "输入消息... (Shift+Enter 换行)"
    - 支持 `Enter` 发送，`Shift+Enter` 换行
- **左侧附件按钮**（可选，后续功能）
- **右侧**：
    - Token 计数显示（当前会话消耗 token 数）
    - 发送按钮（圆形/圆角矩形，主题色）
    - 正在生成时变为"停止"按钮
- 输入区域固定在底部，不随消息滚动

## 五、右侧面板（Right Panel）

这是本次改造最核心的变化——将原有的多个独立页面整合到右侧面板中。

### 5.1 面板结构

```
┌──────────────────────┐
│  [面板标题]     [✕]  │
├──────────────────────┤
│                      │
│  面板内容区域         │
│  (根据选中的功能      │
│   动态切换)          │
│                      │
│                      │
└──────────────────────┘
```

### 5.2 面板模式切换

右侧面板支持以下模式（通过 Tab 或按钮切换）：

#### 模式一：系统指令 / 角色信息（默认模式）

参考 AI Studio 的 "System Instructions" 面板：

- **角色描述**（只读展示 / 快捷编辑）
    - 角色名称
    - 角色描述/Personality
    - 场景描述/Scenario
    - 第一条消息/First Message
    - 点击"编辑"按钮可进入编辑模式
- **系统提示词**（对应当前预设的系统提示）
    - 显示当前激活预设的内容
    - 可快速切换预设（下拉选择器）

#### 模式二：模型参数配置

参考 AI Studio 右侧的 "Run settings" 面板：

- **模型选择**：下拉选择当前 API 配置
- **Temperature**：滑块 (0~2)，带数值输入框
- **Top P**：滑块 (0~1)
- **Top K**：数值输入框
- **Max Output Tokens**：数值输入框
- **Frequency Penalty**：滑块
- **Presence Penalty**：滑块
- 每个参数带有简短说明 Tooltip

#### 模式三：角色管理

将现有 `CharactersView.vue` 的功能嵌入面板：

- 角色列表（网格/列表视图切换）
- 导入角色按钮（支持 SillyTavern 角色卡导入）
- 角色搜索
- 点击角色 → 弹出角色详情 Modal 或在面板内展开
- 创建新角色 → 弹出角色编辑器 Modal

#### 模式四：世界书管理

将现有 `WorldInfoView.vue` 的功能嵌入面板：

- 世界书列表
- 世界书条目列表
- 条目编辑（在面板内或弹出 Modal）
- 导入/导出功能

#### 模式五：预设管理

将现有 `PresetsView.vue` 的功能嵌入面板：

- 预设列表
- 预设编辑器（Prompt 编排）
- 预设内的正则管理
- 导入/导出功能

#### 模式六：正则管理

将现有 `RegexView.vue` 的功能嵌入面板：

- 全局正则规则列表
- 正则规则编辑器
- 启用/禁用切换

#### 模式七：设置

将现有 `SettingsView.vue` 的功能嵌入面板：

- API 配置管理
- 用户设置
- 系统参数
- 密码修改

### 5.3 面板交互

- **展开/收起**：右侧面板通过顶部工具栏的按钮控制显示/隐藏
- **宽度**：默认 360px，可拖拽调整宽度（最小280px，最大50%屏幕宽度）
- **切换动画**：面板内容切换使用平滑的淡入淡出过渡
- **固定/浮动**：
    - PC端默认固定在右侧，挤压主对话区域
    - 可切换为浮动模式（覆盖在对话区域上方）
    - 移动端始终为浮动抽屉模式

## 六、路由改造

### 6.1 路由简化

将现有的多路由方案改为**单路由 + 面板状态**：

| 原路由 | 改造后 |
|--------|--------|
| `/` (ChatView) | 保留，作为唯一主路由 |
| `/characters` | 移除，改为右侧面板模式 |
| `/worldinfo` | 移除，改为右侧面板模式 |
| `/presets` | 移除，改为右侧面板模式 |
| `/regex` | 移除，改为右侧面板模式 |
| `/settings` | 移除，改为右侧面板模式 |
| `/login` | 保留，独立页面 |

### 6.2 URL 参数

使用 query 参数标记面板状态（可选），方便直接链接：

```
/                          → 默认对话界面
/?panel=characters         → 打开角色管理面板
/?panel=settings           → 打开设置面板
/?session=xxx              → 打开特定会话
```

## 七、状态管理改造

### 7.1 新增 App Store 状态

```typescript
interface AppState {
  // 左侧边栏
  leftSidebarCollapsed: boolean;
  leftSidebarVisible: boolean;  // 移动端

  // 右侧面板
  rightPanelVisible: boolean;
  rightPanelMode: 'system' | 'params' | 'characters' | 'worldinfo' | 'presets' | 'regex' | 'settings';
  rightPanelWidth: number;      // 可拖拽调整
  rightPanelPinned: boolean;    // 是否固定（vs 浮动）

  // 设备信息
  isMobile: boolean;
  screenWidth: number;
}
```

### 7.2 面板切换逻辑

- 点击左侧边栏底部的快捷入口按钮 → 设置 `rightPanelMode` 并打开面板
- 如果面板已打开且点击同一个按钮 → 关闭面板
- 点击面板关闭按钮 → 关闭面板
- `ESC` 键 → 关闭面板（移动端）

## 九、视觉设计规范

### 9.1 配色方案（对标 AI Studio）

**亮色主题**：
- 背景：`#ffffff`（主区域），`#f8f9fa`（侧边栏/面板）
- 边框：`#e8eaed`
- 文字：`#1f1f1f`（主要），`#5f6368`（次要）
- 主题色：`#1a73e8`（蓝色，按钮/高亮）
- 消息气泡用户：`#e8f0fe`
- 消息气泡AI：`#f1f3f4`

**暗色主题**：
- 背景：`#1e1e1e`（主区域），`#252525`（侧边栏/面板）
- 边框：`#3c3c3c`
- 文字：`#e3e3e3`（主要），`#9aa0a6`（次要）
- 主题色：`#8ab4f8`（浅蓝色）
- 消息气泡用户：`#1a3a5c`
- 消息气泡AI：`#2d2d2d`

### 9.2 字体

- 主字体：`Google Sans`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `sans-serif`
- 代码字体：`Google Sans Mono`, `Roboto Mono`, `monospace`
- 基础字号：14px
- 消息内容字号：15px
- 行高：1.6

### 9.3 圆角

- 按钮：24px（胶囊形）/ 8px（标准）
- 卡片/面板：12px
- 消息气泡：18px
- 输入框：24px（圆角输入）
- 头像：50%（圆形）

### 9.4 阴影

- 面板阴影：`0 1px 3px rgba(0,0,0,0.12), 0 1px 2px rgba(0,0,0,0.08)`
- 浮动面板：`0 8px 32px rgba(0,0,0,0.15)`
- 悬浮效果：`0 2px 8px rgba(0,0,0,0.1)`

### 9.5 动画

- 面板展开/收起：`300ms cubic-bezier(0.4, 0, 0.2, 1)`
- 消息出现：`200ms ease-out`（从下方滑入 + 淡入）
- 按钮 hover：`150ms ease`
- 主题切换：`400ms ease`（全局 transition）

## 十二、注意事项

1. **保留所有现有业务逻辑**：此次改造仅涉及 UI 布局和交互方式，不涉及后端接口和数据流变更
2. **组件复用**：现有的 `CharacterCard`、`CharacterEditor`、`MessageInput`、`MessageItem`、`WorldInfoEntryEditor`、`RegexEditor`、`PresetRegexManager`、`PromptItemEditor` 等组件应尽量复用，只调整外层容器和布局
3. **Store 复用**：现有的 `characterStore`、`chatStore`、`presetStore`、`worldInfoStore`、`regexRuleStore` 保持不变，仅扩展 `appStore` 添加面板状态
4. **渐进式改造**：可以按里程碑分批实施，每个阶段可独立上线
5. **科幻主题兼容**：现有的科幻背景效果（粒子、网格等）可以保留但需要适配新布局，或考虑简化以匹配 AI Studio 的简洁风格（建议提供开关）
6. **技术栈不变**：继续使用 Vue3 + TypeScript + Naive UI，不引入额外 UI 框架
